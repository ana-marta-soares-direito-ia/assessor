Alerta Phishing

Para o Outlook

Este painel destina-se a ser aberto dentro do Outlook, com uma mensagem aberta. Consulte as instruções de instalação.

Activação

Cole o código de activação que recebeu depois do pagamento. A activação faz-se uma única vez.

Abra uma mensagem recebida para a analisar. Para o painel acompanhar todas as mensagens, fixe-o com o alfinete no canto superior.

Remetentes de confiança

Para estes endereços não são assinalados o nome da entidade nem o endereço de resposta. Os restantes sinais continuam a ser verificados.
